Q1. Create a Java program to manage Student details using a Student class with name, rollNumber and marks. Include inputDetails() and displayDetails().

File: Student.java   Type: Java

Steps to run

  1. Save as Student.java.
  2. Open CMD/VS Code terminal in that folder.
  3. Run: javac Student.java
  4. Run: java Student

Program code

import java.util.Scanner;

class Student {
    String name;
    int rollNumber;
    float marks;

    void inputDetails() {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter Student Name: ");
        name = sc.nextLine();

        System.out.print("Enter Roll Number: ");
        rollNumber = sc.nextInt();

        System.out.print("Enter Marks: ");
        marks = sc.nextFloat();
    }

    void displayDetails() {
        System.out.println("\n--- Student Details ---");
        System.out.println("Name: " + name);
        System.out.println("Roll Number: " + rollNumber);
        System.out.println("Marks: " + marks);
    }

    public static void main(String[] args) {
        Student s = new Student();
        s.inputDetails();
        s.displayDetails();
    }
}

Q6. Demonstrate hierarchical inheritance: Student, Teacher and Administrator inherit from Person and have their own attributes.

File: HierarchicalInheritance.java   Type: Java

Steps to run

  1. Save as HierarchicalInheritance.java.
  2. Run: javac HierarchicalInheritance.java
  3. Run: java HierarchicalInheritance

class Person {
    String name;
    int age;

    void displayPerson() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

class Student extends Person {
    String course;
    int rollNumber;

    void displayStudent() {
        displayPerson();
        System.out.println("Course: " + course);
        System.out.println("Roll Number: " + rollNumber);
    }
}

class Teacher extends Person {
    String subject;

    void displayTeacher() {
        displayPerson();
        System.out.println("Subject: " + subject);
    }
}

class Administrator extends Person {
    String department;

    void displayAdministrator() {
        displayPerson();
        System.out.println("Department: " + department);
    }
}

public class HierarchicalInheritance {
    public static void main(String[] args) {
        Student s = new Student();
        s.name = "Rahul";
        s.age = 20;
        s.course = "B.Tech";
        s.rollNumber = 101;

        Teacher t = new Teacher();
        t.name = "Meera";
        t.age = 35;
        t.subject = "Java";

        Administrator a = new Administrator();
        a.name = "Amit";
        a.age = 40;
        a.department = "Administration";

        System.out.println("--- Student Details ---");
        s.displayStudent();

        System.out.println("\n--- Teacher Details ---");
        t.displayTeacher();

        System.out.println("\n--- Administrator Details ---");
        a.displayAdministrator();
    }
}

Q7. Write a Java Servlet program to display a welcome message in a web browser.

File: WelcomeServlet.java   Type: Servlet (Tomcat 10+)

Steps to run

  1. Install JDK and Apache Tomcat 10.1 or newer.
  2. Create a web project with WEB-INF/classes and WEB-INF/lib folders.
  3. Add the Jakarta Servlet API to the project compile classpath (or use a Maven web project with jakarta.servlet-api as provided).
  4. Save this class as WelcomeServlet.java and compile it against the Tomcat Jakarta Servlet API.
  5. Place WelcomeServlet.class in WEB-INF/classes; deploy the project under Tomcat webapps.
  6. Start Tomcat and open http://localhost:8080/ProjectName/welcome

Program code

import java.io.IOException;
import java.io.PrintWriter;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

@WebServlet("/welcome")
public class WelcomeServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest request,
                         HttpServletResponse response)
                         throws ServletException, IOException {
        response.setContentType("text/html;charset=UTF-8");

        PrintWriter out = response.getWriter();
        out.println("<!DOCTYPE html>");
        out.println("<html><body>");
        out.println("<h1>Welcome to Java Servlet Programming!</h1>");
        out.println("</body></html>");
    }
}

Q8. Write a Servlet program to accept a user's name from an HTML form and display the name.

File: NameServlet.java   Type: Servlet (Tomcat 10+)

Steps to run

  1. Use the same Tomcat web project setup as Q7.
  2. Save as NameServlet.java and compile against the Jakarta Servlet API.
  3. Place NameServlet.class in WEB-INF/classes and deploy the project.
  4. Start Tomcat and open http://localhost:8080/ProjectName/name.
  5. Enter a name and submit the form; the servlet displays the greeting.

Program code

import java.io.IOException;
import java.io.PrintWriter;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

@WebServlet("/name")
public class NameServlet extends HttpServlet {
    private void showForm(HttpServletResponse response,
                          String message) throws IOException {
        response.setContentType("text/html;charset=UTF-8");
        PrintWriter out = response.getWriter();

        out.println("<!DOCTYPE html><html><body>");
        out.println("<h2>Student Name Form</h2>");
        out.println("<form method='post' action='name'>");
        out.println("Enter Name: <input type='text' name='username' required>");
        out.println("<input type='submit' value='Submit'>");
        out.println("</form>");
        if (message != null) {
            out.println("<h3>" + message + "</h3>");
        }
        out.println("</body></html>");
    }

    @Override
    protected void doGet(HttpServletRequest request,
                         HttpServletResponse response)
                         throws ServletException, IOException {
        showForm(response, null);
    }

    @Override
    protected void doPost(HttpServletRequest request,
                          HttpServletResponse response)
                          throws ServletException, IOException {
        String name = request.getParameter("username");
        if (name == null) name = "";
        name = name.replace("&", "&amp;")
                   .replace("<", "&lt;")
                   .replace(">", "&gt;")
                   .replace("\"", "&quot;")
                   .replace("'", "&#x27;");
        showForm(response, "Welcome " + name);
    }
}

Q11. Develop a JDBC application to manage student records with insert, update, delete and display operations.

File: StudentJDBC.java   Type: Java + MySQL JDBC

Database setup

CREATE DATABASE college;
USE college;

CREATE TABLE students (
    roll_no INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    marks FLOAT NOT NULL
);

Steps to run

  1. Install MySQL Server and create the database/table using the SQL below.
  2. Download MySQL Connector/J and add its JAR to the project's referenced libraries/classpath.
  3. Update DB_USER and DB_PASSWORD in the code.
  4. Compile with the Connector/J JAR on the classpath: javac -cp .;mysql-connector-j.jar StudentJDBC.java (Windows).
  5. Run with: java -cp .;mysql-connector-j.jar StudentJDBC

Program code

import java.sql.*;
import java.util.Scanner;

public class StudentJDBC {
    static final String URL =
        "jdbc:mysql://localhost:3306/college";
    static final String USER = "root";
    static final String PASSWORD = "your_password";

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in);
             Connection con = DriverManager.getConnection(
                 URL, USER, PASSWORD)) {

            while (true) {
                System.out.println("\n1.Insert  2.Update  3.Delete  4.Display  5.Exit");
                System.out.print("Enter choice: ");
                int choice = sc.nextInt();

                if (choice == 1) {
                    System.out.print("Roll number: ");
                    int roll = sc.nextInt();
                    sc.nextLine();
                    System.out.print("Name: ");
                    String name = sc.nextLine();
                    System.out.print("Marks: ");
                    float marks = sc.nextFloat();

                    String sql = "INSERT INTO students VALUES (?, ?, ?)";
                    try (PreparedStatement ps = con.prepareStatement(sql)) {
                        ps.setInt(1, roll);
                        ps.setString(2, name);
                        ps.setFloat(3, marks);
                        ps.executeUpdate();
                        System.out.println("Record inserted.");
                    }
                } else if (choice == 2) {
                    System.out.print("Roll number to update: ");
                    int roll = sc.nextInt();
                    sc.nextLine();
                    System.out.print("New name: ");
                    String name = sc.nextLine();
                    System.out.print("New marks: ");
                    float marks = sc.nextFloat();

                    String sql = "UPDATE students SET name=?, marks=? WHERE roll_no=?";
                    try (PreparedStatement ps = con.prepareStatement(sql)) {
                        ps.setString(1, name);
                        ps.setFloat(2, marks);
                        ps.setInt(3, roll);
                        System.out.println(ps.executeUpdate() + " record(s) updated.");
                    }
                } else if (choice == 3) {
                    System.out.print("Roll number to delete: ");
                    int roll = sc.nextInt();

                    try (PreparedStatement ps = con.prepareStatement(
                            "DELETE FROM students WHERE roll_no=?")) {
                        ps.setInt(1, roll);
                        System.out.println(ps.executeUpdate() + " record(s) deleted.");
                    }
                } else if (choice == 4) {
                    try (Statement st = con.createStatement();
                         ResultSet rs = st.executeQuery(
                             "SELECT * FROM students ORDER BY roll_no")) {
                        System.out.println("Roll No\tName\tMarks");
                        while (rs.next()) {
                            System.out.println(
                                rs.getInt("roll_no") + "\t" +
                                rs.getString("name") + "\t" +
                                rs.getFloat("marks"));
                        }
                    }
                } else if (choice == 5) {
                    System.out.println("Exiting...");
                    break;
                } else {
                    System.out.println("Invalid choice.");
                }
            }
        } catch (SQLException e) {
            System.out.println("Database error: " + e.getMessage());
        }
    }
}

  1. Save as email-validation.html.
  2. Open in a browser or use VS Code Live Server.

Program code

    <title>Email Validation</title>
</head>
<body>
    <h2>Email Validation</h2>
    <input type="text" id="email" placeholder="Enter email address">
    <button onclick="validateEmail()">Validate</button>
    <p id="result"></p>

    <script>
        function validateEmail() {
            const email = document.getElementById("email").value.trim();
            const pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

            if (pattern.test(email)) {
                document.getElementById("result").textContent =
                    "Valid email address";
            } else {
                document.getElementById("result").textContent =
                    "Invalid email address";
            }
        }
    </script>

Q15. Create an HTML form using JavaScript to validate student name, email and password.

File: student-validation.html   Type: HTML + JavaScript

Steps to run

  1. Save as student-validation.html.
  2. Open in a browser or use VS Code Live Server.
  3. Try submitting empty or invalid fields, then enter valid details.

Program code

<!DOCTYPE html>
<html>
<head>
    <title>Student Form Validation</title>
</head>
<body>
    <h2>Student Registration Form</h2>

    <form onsubmit="return validateForm()">
        <label>Name:</label>
        <input type="text" id="name"><br><br>

        <label>Email:</label>
        <input type="text" id="email"><br><br>

        <label>Password:</label>
        <input type="password" id="password"><br><br>

        <button type="submit">Register</button>
    </form>

    <p id="message"></p>

    <script>
        function validateForm() {
            const name = document.getElementById("name").value.trim();
            const email = document.getElementById("email").value.trim();
            const password = document.getElementById("password").value;
            const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

            if (name === "") {
                showMessage("Please enter your name.");
                return false;
            }
            if (!emailPattern.test(email)) {
                showMessage("Please enter a valid email.");
                return false;
            }
            if (password.length < 8) {
                showMessage("Password must contain at least 8 characters.");
                return false;
            }

            showMessage("Registration form submitted successfully!");
            return false;
        }

        function showMessage(text) {
            document.getElementById("message").textContent = text;
        }
    </script>
</body>
</html>
